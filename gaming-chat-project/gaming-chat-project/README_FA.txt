Gaming.Chat — نسخهٔ اولیهٔ قابل بسته‌بندی برای Windows و Android

مهم: این پروژه یک نسخهٔ آغازین است، نه پیام‌رسان کامل. قابلیت‌های این نسخه: ثبت‌نام با ایمیل/رمز، شناسهٔ ۸ رقمی، جست‌وجوی شناسه و پیام خصوصی زنده. تماس صوتی/تصویری، گروه‌ها، کانال‌ها، ارسال فایل و بازیابی/مدیریت پیشرفتهٔ حساب هنوز ساخته نشده‌اند.

پیش‌نیاز روی ویندوز:
- Node.js نصب باشد (روی رایانهٔ شما قبلاً نصب شده است).
- برای APK: Android Studio و Android SDK نصب شود.
- برای استفادهٔ آنلاین: حساب Google و پروژه Firebase لازم است. طرح رایگان Firebase ممکن است محدودیت و شرایط تغییرپذیر داشته باشد.

راه‌اندازی سرور مشترک رایگان:
1) به https://console.firebase.google.com برو و Add project را بزن.
2) در پروژه، Authentication > Sign-in method > Email/Password را فعال کن.
3) Firestore Database را ایجاد کن.
4) محتوای firestore.rules را از Firebase Console > Firestore > Rules کپی و Publish کن.
5) در Project settings > Your apps یک Web app بساز.
6) مقادیر firebaseConfig را در src/firebase-config.js جایگزین کن. فقط مقدارها را عوض کن؛ نام فیلدها را تغییر نده.
7) قبل از انتشار عمومی، قوانین را بازبینی و تست کن. کلیدهای تنظیمات وب Firebase به‌تنهایی رمز نیستند؛ قوانین دیتابیس امنیت داده‌ها را کنترل می‌کنند.

ساخت نسخهٔ ویندوز:
1) این پوشه را در File Explorer باز کن.
2) روی نوار آدرس پوشه کلیک کن، cmd بنویس و Enter بزن.
3) اجرا کن: npm install
4) اجرا کن: npm run dist:win
5) اگر build موفق باشد، فایل نصب در پوشه dist/../release یا خروجی electron-builder ساخته می‌شود (معمولاً پوشه release). اگر خطا دیدی، متن کامل خطا را بفرست.

ساخت نسخهٔ اندروید:
1) Android Studio را نصب کن و یک بار باز کن تا SDK را نصب کند.
2) در همان پوشهٔ پروژه CMD باز کن.
3) اجرا کن: npm install
4) اجرا کن: npm run android:init
   اگر گفت android از قبل وجود دارد، ادامه بده.
5) اجرا کن: npm run android:sync
6) اجرا کن: npm run android:open
7) Android Studio باز می‌شود. صبر کن Gradle Sync تمام شود.
8) از منوی Build > Build Bundle(s) / APK(s) > Build APK(s) استفاده کن.
9) APK آزمایشی معمولاً در android/app/build/outputs/apk/debug/app-debug.apk ساخته می‌شود.

نکته‌های مهم:
- برنامهٔ ویندوز و اندروید از یک Firebase project استفاده می‌کنند و پیام‌های خصوصی از آن مسیر می‌گذرند.
- ورود با ایمیل و رمز است؛ شماره تلفن لازم نیست. این نسخه برای ثبت‌نام، ایمیل معتبر می‌خواهد. نام کاربری به‌تنهایی برای ورود پیاده‌سازی نشده است.
- شناسهٔ ۸ رقمی برای پیدا کردن کاربر است، نه رمز ورود.
- نسخهٔ فعلی پیاده‌سازی اولیه است و پیش از استفادهٔ واقعی باید از نظر امنیت، محدودسازی تلاش‌ها، حذف/گزارش کاربر، قوانین Firestore و مدیریت خطاها بررسی شود.
