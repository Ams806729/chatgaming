# Gaming.Chat — راهنمای فارسی

این پروژه یک نسخهٔ اولیهٔ واقعی برای آزمایش است: ساخت حساب با نام کاربری و رمز، شناسهٔ یکتای ۸ رقمی، پیام خصوصی زنده، تاریخچهٔ پیام‌ها، نمایش آنلاین بودن و ارسال فایل تا ۱۰ مگابایت.

## اجرای ساده روی ویندوز
1. Node.js نسخهٔ 20 یا جدیدتر نصب باشد.
2. پوشهٔ پروژه را باز کن.
3. در نوار آدرس File Explorer بنویس `cmd` و Enter بزن.
4. اجرا کن:
   ```bat
   npm install
   npm start
   ```
5. مرورگر را روی `http://localhost:3000` باز کن.

## انتشار آنلاین روی Render
1. کل محتوای این پوشه را در مخزن GitHub آپلود کن.
2. در Render روی New + و سپس Web Service بزن و مخزن را وصل کن.
3. Root Directory را خالی بگذار اگر `package.json` در ریشهٔ مخزن است.
4. Build Command: `npm install`
5. Start Command: `npm start`
6. پلن Free را فقط اگر در صفحهٔ Render موجود است انتخاب کن؛ قبل از تأیید نهایی بررسی کن هزینه صفر باشد.
7. در بخش Environment Variables یک مقدار تصادفی و طولانی برای `SESSION_SECRET` تنظیم کن.

## محدودیت مهم انتشار رایگان
این نسخه از `data.json` برای ذخیره‌سازی حساب‌ها و پیام‌ها استفاده می‌کند. در Render رایگان، فایل‌های محلی ممکن است هنگام راه‌اندازی مجدد یا انتشار پاک شوند؛ بنابراین این پروژه را تا زمانی که پایگاه دادهٔ پایدار وصل نشده، برای اطلاعات مهم یا استفادهٔ عمومی معرفی نکن. آپلود فایل‌ها نیز روی دیسک محلی است و ممکن است پاک شود. برای محصول پایدار باید دیتابیس مدیریت‌شده و ذخیره‌سازی فایل دائمی وصل شود.

## نسخهٔ ویندوز
برای ساخت فایل نصب روی ویندوز:
```bat
npm install
npm run dist:win
```
فایل نصب در پوشهٔ `release` ساخته می‌شود. این دستور را روی ویندوز اجرا کن.

## نسخهٔ اندروید
برای ساخت APK به Android Studio و Android SDK نیاز است:
```bat
npm install
npm run android:init
npm run android:sync
npm run android:open
```
سپس در Android Studio پروژه را Build کن. برای استفادهٔ آنلاین، آدرس API/سرور باید قبل از ساخت نهایی تنظیم شود؛ `localhost` در موبایل به خود گوشی اشاره می‌کند، نه کامپیوتر.

## قابلیت‌هایی که هنوز در این نسخه نیستند
گروه‌ها، کانال‌ها، تماس صوتی/تصویری، اعلان‌های قابل اتکا، بازیابی رمز عبور، تعدیل محتوا و ذخیره‌سازی دائمی فایل‌ها پیاده‌سازی نشده‌اند. این‌ها به توسعه و آزمایش جداگانه نیاز دارند.
